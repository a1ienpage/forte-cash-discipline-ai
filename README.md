# ForteBank Cash Discipline AI — Datathon'26

Локальный сервис анализа видео кассовых операций: компьютерное зрение формирует кандидатов событий, мультимодальная модель проверяет их по кадрам, нормативный слой формирует описание, таймкод и доказательства.

## Демонстрация для жюри

- Веб-интерфейс: https://sensitive-absent-portfolio-mattress.trycloudflare.com
- API base URL: https://sensitive-absent-portfolio-mattress.trycloudflare.com/api/v1
- Проверка состояния: `/api/v1/health`
- Ключ `X-API-Key` передан жюри отдельно через форму. В репозитории ключа нет.

Ссылка временная: сервис и модель работают на MacBook, доступ обеспечивается Cloudflare Tunnel.

## Архитектура

- FastAPI и очередь изолированных процессов с таймаутом.
- PyAV: чтение видео и временные метки PTS.
- YOLO11s: детекция объектов и построение гипотез.
- Qwen2.5-VL-7B-Instruct, 4-bit, MLX: обзорные окна и уточняющая проверка кандидатов.
- Проверка структуры ответа, визуальных условий и доказательных JPEG-кадров.
- 9 активных правил и 11 диагностических категорий; нормативные ссылки включены в ответ.

Основные файлы: `app/analyzer.py`, `app/cv_detector.py`, `app/vlm_engine.py`, `app/regulations.py`, `app/video_decoder.py`, `app/worker.py`, `app/main.py`.

## Локальный запуск

Целевая платформа: macOS на Apple Silicon, 16 ГБ объединённой памяти, Python 3.13. Точные версии зависимостей находятся в `uv.lock` и `requirements.lock.txt`.

```bash
uv sync --frozen --python 3.13
```

Перед офлайн-запуском один раз загрузите модели при наличии интернета:

```bash
uv run --frozen python -c "from huggingface_hub import snapshot_download; snapshot_download('mlx-community/Qwen2.5-VL-7B-Instruct-4bit', revision='fdcc572e8b05ba9daeaf71be8c9e4267c826ff9b')"
uv run --frozen python -c "from ultralytics import YOLO; YOLO('yolo11s.pt')"
```

Сервис требует локальный кэш указанной ревизии Qwen и `yolo11s.pt` в корне проекта. Веса не включены в Git.

Создайте собственный ключ и запустите сервер:

```bash
export FORTE_API_KEY="$(python3 -c 'import secrets; print(secrets.token_urlsafe(32))')"
bash start_service.sh
```

Ключ сохраните у себя для последующих запросов. Для постоянного локального хранения поддерживается файл `.forte_api_key`, исключённый из Git. `.env.example` — пример переменных; файл `.env` автоматически не загружается.

Откройте `http://localhost:8000`. При необходимости публичного доступа запустите отдельно `cloudflared tunnel --url http://localhost:8000`; используйте адрес, выданный именно вашим процессом.

## API

```bash
curl -X POST http://localhost:8000/api/v1/analyze \
  -H "X-API-Key: $FORTE_API_KEY" \
  -F "file=@sample.mov" \
  -F "vlm_mode=auto"

curl http://localhost:8000/api/v1/jobs/JOB_ID \
  -H "X-API-Key: $FORTE_API_KEY"
```

POST возвращает идентификатор фоновой задачи. Итоговый ответ содержит `verdict`, `violations`, `timecode_sec`, описание, нормативные ссылки, доказательные кадры и диагностику. Статусы задачи: `processing`, `done`, `failed`. По умолчанию используется гибридный конвейер.

## Проверки и результаты

На локальном полном комплекте данных этой версии прошли **25/25 приёмочных тестов**. Это проверка программных свойств, а не accuracy модели.

Свежие контрольные прогоны `hybrid + auto`:

| Видео | Результат | Время события | Официальная метка | Время анализа |
|---|---|---:|---:|---:|
| Х-26 | `violation` | 17,6 с | 9,0 с | 67,1 с |
| Х-4 | `violation` | 56,6 с | 57,0 с | 212,5 с |

Оба бинарных ответа верны. Ошибка локализации Х-26 относительно официальной метки — 8,6 секунды. Это два контрольных видео, не независимая оценка всего набора.

**Свежий полный hybrid-прогон текущей версии на 42 видео не выполнен.** `REPORT.md` и `evaluation/results/` сохраняют исторические результаты для воспроизводимости: старый hybrid — 24/42 (57,14%). Обновлённые хэши в прежних артефактах не означают повторного инференса. Аугментации служат проверкой устойчивости, а не независимым тестовым набором. MEVA используется для внешней диагностики; она не заменяет банковскую разметку.

Для полной локальной оценки отдельно восстановите исходные 42 видео в `open/videos/`, XLSX организаторов, аугментации и тестовые медиаданные по манифестам. Они намеренно не опубликованы. Без этих файлов полный приёмочный набор не запустится успешно.

```bash
uv run --frozen pytest -v tests/test_acceptance_suite.py
uv run --frozen python evaluation/run_stage5_evaluation.py --configs hybrid --vlm-mode auto
```

## Состав публикации и ограничения

Включены код, интерфейс, lock-файлы, тесты, скрипты оценки, текстовые аннотации и исторические отчёты. Исключены ключи, пользовательские загрузки, видео, веса, виртуальные окружения и архивные версии кода.

Известные ограничения: чувствительность фильтра домена к формулировкам, ошибки временной локализации, максимум два события в одном ответе VLM, зависимость полноты наблюдений от видимости и выборки кадров. Работа на неизвестных ракурсах и высокий accuracy не гарантируются.
